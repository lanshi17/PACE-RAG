# PACE-RAG 后续研究计划：适用性约束的证据集合选择

日期：2026-10-10。版本：v1.0。代码与结果基线：`51006f0`。

状态：研究计划已制定，以下新增实现、实验和专家审核均未因此完成。本文承接
[上一轮优化计划](../2026-10-08/followup-plan.md)的交付收官，细化
[研究主文档](../2026-09-12/prenatal-ace-framework.md)中的方法假设；本轮实验采用新协议和结果目录，
不改写历史预注册与冻结产物。正式测试前另行冻结配置、样本量和分析协议。

## 1. 研究目标与当前证据

本轮回答一个问题：**在相同语料、生成器和上下文预算下，联合考虑临床适用性、证据角色与
版本有效性，能否比简单过滤和常规去冗余更少地使用不适用证据，同时保持回答质量？**

预期贡献落在条件与证据集合选择的联合机制。BM25、RRF、三值判断、来源限额、引用编号和
正则后检分别作为已有技术或工程措施；不能仅凭组合声称首创。完整方法优于强简单对照、
独立题集上的收益及消融归因，是升级算法创新主张的必要证据。

### 1.1 已有结果及其解释边界

| 证据 | 当前事实 | 对本计划的约束 |
| --- | --- | --- |
| 四框架统一评测 | 成熟 50 题 final：LightRAG 0.9279、HippoRAG 0.9090、KAG 0.9067、GraphRAG 0.8733；四框架全集均 62/62、`n_failed=0` | 完整 PACE 尚未入榜；LightRAG 成绩不能计为 PACE 收益 |
| 统计比较 | Friedman `p=0.0901`；六对 Holm 校正仅 GraphRAG−LightRAG 显著，`p_holm=0.0168` | 不声称四框架具有完整的显著排序 |
| LightRAG−KAG | 成熟集均值差约 +0.0213，`p_holm=0.5588` | 表述为未检出显著差异，不表述为等效或差异消失 |
| 历史 B1 后置过滤 | B0_ctrl 0.8795 → B1 0.8815；2/50 题触发，共丢弃 6 条上下文 | 增益小且触发面有限；不能据此证明条件化方法普遍有效或无效 |
| 历史三通道消融 | recall 0.94 → 0.98，final +0.0011，faithfulness/completeness 回退 | 优先研究证据取舍，不能只汇报检索收益 |
| 版本引用核验 | 50 题两臂各发现 1 个 `stale_only`；B0_ctrl/B1 分别有 36/35 题 `no_citations` | 先提高可核验覆盖率；没有引用不能当作核验通过的证据 |
| PU-L4-002 安全探针 | 历史与新 baseline 合计四次观测三次违规；单次 A/B 两臂均未违规 | 不估计稳定违规率，不宣称后缀已证明有效，也不把后检建议当作已证实根因 |
| 跨框架合并探针 | 本轮已有 no-go 决策 | 暂不扩展合并链路；逐题取两答案最高分只约束答案选择器，不是重新合并上下文后生成的数学上界 |

数值来源：[当前汇总](../../benchmark/results/unified62/summary.json)、
[四框架报告](../../benchmark/report/unified62-final-4fw-20261009.md)、
[批次十](../2026-09-15/pace-foundation-batch-10.md)、

### 1.2 实现盘点

| 能力 | 已有实现 | 本轮需要补齐 |
| --- | --- | --- |
| 证据来源与锚点 | `evidence_store` 保存来源身份、规范化文本、页/span 与哈希 | 运行时上下文、生成引用和核验结果共用稳定锚点，保存完整映射 |
| 三值适用性 | `conditions/filter.py`、孕周以天判断、Unknown 保留 | 条件必须绑定原始条款；审计同一 chunk 内多条建议被错误合并的情况 |
| 过滤前置 | 图/向量 `rank(..., candidates=...)` 接口已有 | `Bm25Index.search` 尚无池参数；需补池内筛选及截断顺序，不能先取 top-k 再冒充全池过滤 |
| 来源去冗余 | `rrf.py::diverse_top_k` 及单测已有 | 接入运行时宽候选，不能在已截断的 16 条上去冗余后没有候选可补 |
| 证据集合选择 | `select_evidence` 按适用性、角色与版本分桶 | 当前主要是保序分桶；角色覆盖、互补性与预算优化仍需实现并接入生成 |
| 版本后检 | `verify_version_citations` 已接入 B1 评估 | 缺引用与不可得新版单列；检测、修正和答案质量分别评估 |
| 评测入口 | 旧 B1 复用冻结上下文；另有两/三通道运行时脚本 | 新增统一多臂运行时入口，共用打分逻辑，落实 required Judge 与 safety verdict |

`prefiltered_pool` 是上一版设计中的名称，当前可复用的实际函数是
`condition_seed_anchors`；实现时以源码为准。代码模块完成、接线完成与端到端收益验证
分开验收，不将上一轮“6/6 交付”解释为本轮研究假设已证实。

## 2. 研究假设与贡献判定

| 编号 | 假设 | 必须排除的替代解释 | 支持或降低主张的依据 |
| --- | --- | --- | --- |
| H1 | 过滤位置和去冗余能改善上下文取舍 | 两个改动混在一起、候选截断、prompt 改动、生成随机性 | 2×2 因子实验分别估计两个主效应及交互；结果只作为开发证据 |
| H2（主线） | 适用性×角色×版本的集合选择优于强简单方案 | 仅靠 metadata filter、MMR、来源限额或增加上下文即可获得同样收益 | 隐藏集上完整 PACE 优于冻结的强简单对照，且质量护栏通过 |
| H3 | 确定性核验可以发现版本与条件使用错误 | 缺引用逃过检查、正则误报、全面拒答造成“安全”假象 | 报告覆盖率、误报/漏报、有效回答率；修正效果需独立对照 |

查新任务先建立“方法—相似点—差异—需验证主张”矩阵，至少覆盖 LightRAG、
metadata/区间过滤、MMR/集合选择、临床资格与条件匹配、版本与冲突处理、引用支持核验。
从[既有先例核查](../2026-09-12/prenatal-ace-framework-followup.md)出发重新核对原文与公开日期；
文献检索未命中不能证明首创，尚未实施的多模态与领域训练不列为当前贡献。

## 4. R0–R1：先把 B1 的效果拆清楚

### 4.1 统一输入与真正的运行时实验臂

1. 从当前 26 文档语料和同一索引快照重取宽候选，保存每路排名、原始分数、来源与锚点。
   可缓存这份宽候选用于四臂复用，不能复用旧 B0 已选好的 16 条上下文来检验检索改动。
2. 冻结 BM25 参数、图种子/扩展预算、向量模型与桥接规则。R1 不同时改图遍历算法或
   重新估计过滤后 BM25 的 IDF；先隔离候选筛选相对截断的位置。
3. 定义每路候选上限 M、最终 `k≤16` 和证据 token 上限 B；R0 初始候选为
   `M=40`、`B=8192`，只在开发阶段检查可行性后冻结。用于装包的宽候选深度另行记录，
   不允许已被上游 top-k 丢掉的候选被误称为已评估。
4. B 包括证据文本、条件/角色标记及引用标识。各臂使用同一 tokenizer、装包规则与输出上限；
   完整锚点超预算时跳过并继续，必要拆块必须在所有臂共用的预处理阶段完成。
   报告实际上下文条数和 token 数，同一上限不等于实际用量完全一致。
5. 条件解析只读问题与允许的用户输入，禁止读 `gold_answer`、`must_have` 或测试标签。
   三值判定和来源映射全程保留；不得把 Unknown 直接当作 Inapplicable 丢弃。

### 4.2 四臂设计

F 表示过滤位置，D 表示来源限额。两水平过滤均排除明确不适用材料作为直接回答上下文，
只改变排除发生的位置。R1 不以跨版本比较题来声称完整冲突保留能力，该能力在 R3 单独验证。

| 实验臂 | F：过滤位置 | D：来源去冗余 | 顺序 |
| --- | --- | --- | --- |
| A00 | 后置 | 关闭 | 每路截断 → RRF → 预算选取 → 条件过滤，不补位 |
| A10 | 前置 | 关闭 | 宽排名内条件过滤 → 每路截断 → RRF → 预算选取 |
| A01 | 后置 | 开启 | 每路截断 → RRF → 来源限额与预算选取 → 条件过滤，不补位 |
| A11 | 前置 | 开启 | 宽排名内条件过滤 → 每路截断 → RRF → 来源限额与预算选取 |

来源限额开发候选为 `max_per_source∈{1,2,3}`，先用离线检索结果选定一个配置，再运行
四臂生成；不得在每道测试题上择优。四臂共享生成 prompt、输出格式、模型、Judge 与安全评分。
RRF 常数与来源等价映射也必须相同。后置臂因过滤而少用上下文是处理机制的一部分，需报告；
若据此声称质量/成本优势，另做相同 token 用量的开发敏感性分析。

对每题、每次重复的指标 Y，计算：

```text
前置过滤主效应 = [(Y10 − Y00) + (Y11 − Y01)] / 2
来源去冗余主效应 = [(Y01 − Y00) + (Y11 − Y10)] / 2
交互效应 = Y11 − Y10 − Y01 + Y00
```

开发主指标为 final，同时报告 faithfulness、completeness、correctness、recall、
适用性触发率、上下文变化率、来源集中度、实际 token 与失败。先以现有 50 题完成回归，
再在 R2 开发试标集看针对性表现；不得只汇报发生改善的题。

默认每臂每题 **3 次独立生成**，不因两臂上下文相同就共享答案。旧 B1 会在未过滤题上复用
答案，不能直接承担本实验的生成方差估计。无条件变化题允许上下文变化，但要检查答案是否
发生无依据变化；若“无不适用候选且关闭 D”时前后置仍不同，必须解释接线差异。

R1 交付包含全部四臂及主效应/交互；若平均收益小、区间宽或质量回退，记录未证实收益。
某臂在开发集获胜只用于冻结配置，不转述为独立验证成功。

## 5. R2：数据集与标注

### 5.1 分清开发、历史回归和隐藏测试

- 现有 50 题已经反复用于设计与调参，本轮作为开发/回归集，不再充当未见测试集。
- 已公开且看过结果的 12 道草案，即使以后审核通过也用于开发或历史复核；其中 6 道 L4
  安全草案的专家审核仍为外部依赖。隐藏题需要另建，不能通过改写这些题获得“独立性”。
- 先安排约 10 个新情境家族作开发试标与工作量估计，不进入最终测试。随后按五类任务
  各约 12 个家族规划隐藏集：孕周边界/区间、人群/检查方法、条件缺失、版本/真实冲突、
  互补证据/同源冗余。初始规划共 60 个家族，每家族约 3 个变体，约 180 题。
- 每家族包含原始情境、只改一个有医学依据的关键条件、答案应保持稳定的对照变体。
  哪些内容应变/不应变由原文与专家确定，不能预设“条件一变答案就必须变”。
- **60 个家族是资源估算起点，不是统计充分性的保证。** 依据开发集的基线错误率、
  配对不一致比例、家族内相关性和预定最小效应做功效/精度模拟，冻结最终家族数。
  达不到目标则明确报告探索性或精度不足，不以增加同一题的改写充当独立样本。

以临床情境家族隔离开发与测试，近义改写、条件变体、同一推理模板不得跨集合。
来源家族与版本链也检查交叉；若同一小语料无法实现来源隔离，只主张同语料下的新情境泛化，
跨来源泛化另设留出实验。gold 原文进入检索语料是正常 RAG 设置，测试答案和标签不能进入
规则、角色模板、提示调优或检索索引。

### 5.2 每题必须具备的审核材料

| 材料 | 要求 |
| --- | --- |
| 身份与分组 | `question_id`、`scenario_family_id`、任务类别、变体类型、开发/测试状态 |
| 适用条件 | 已知条件、未知条件、条件改变的依据，以及允许直接建议或仅条件解释的范围 |
| 原文支持 | `source_id`、版本、页/span、原文摘录、证据角色及其审核状态 |
| 预期行为 | 必需陈述、禁止断言、应改变与应保持的内容；无法回答时的合理解释范围 |
| 冲突与版本 | 双侧原文、适用范围是否相同、替代关系及范围；缺源题单列 |
| 审核记录 | 两人独立标签、分歧与仲裁、最终版本与数据指纹；无占位审核者或虚构一致性 |

隐藏集 gold 冻结后，对匿名化系统答案开展独立、盲法评审。主比较两臂的全部重复答案均纳入
审核预算；LLM Judge 不能代替主终点的专家标签。来源不足或 gold 无法定稿的题在运行前归入
“缺证据行为”专层或剔除并登记，不依据系统分数决定去留。流程沿用
[现有专家审核方案](../../benchmark/qa/dataset/PRECLINICAL_REVIEW.md)。

## 6. R3：从简单过滤推进到联合集合选择

### 6.1 实现范围

在固定宽候选和预算下，沿用主文档 §5.2 的目标，权衡角色覆盖、相关性、互补支持、冗余与
不兼容合用。先实现可解释的确定性选择，不默认引入训练；权重、预算、角色模板仅在开发集
确定。对小候选集与穷举或整数规划结果比较选择损失，不声称通用近似最优保证。

- 角色由问题和经审核模板推导；测试集的专家角色标注只用于评估。直接注入金标准角色的
  实验单列为 oracle，不混入主结果。
- Applicable 才可能承担个体化直接支持；Unknown 保留为条件说明或需澄清材料，
  不自动补成患者事实，也不导致一律拒绝一般知识解释。
- 主支持池与比较/未知材料分开管理，共用总预算。前置过滤不能把用户所需的版本比较材料
  永久删掉；对相同适用情境下的真实分歧保留双方，不能借“去冗余”消除冲突。
- 版本替代以可核实关系及条款范围为准；部分更新不能直接推导整份旧文档失效。
- 输出到生成器的不仅是文本，还包括适用状态、证据角色与来源锚点；验证生成端实际读取
  这些信息。当前分桶模块独立可测，不代表这些约束已经落实到生成答案。

### 6.2 主对照与消融

| 实验臂 | 检索与选择 | 用途 |
| --- | --- | --- |
| L：LightRAG 控制 | LightRAG 检索，统一上下文预算、生成 prompt 与输出契约 | 判断完整方案相对实用底座的收益 |
| S：强简单对照 | 与 P 共用宽候选、可用元数据及三值判断；开发集选定的过滤 + 来源限额或 MMR | **主比较对象**，排除简单方法已能解决问题 |
| P：完整 PACE | 与 S 同候选，采用角色/适用性/版本联合选择及证据角色呈现 | 检验 H2 |

S 的最佳方案在测试前选定并冻结。L 采用同生成器的检索控制定义，区别于历史保留原生
prompt 的四框架实验；需要比较原生端到端系统时另列实验，不拼接旧分数。

开发阶段补做去掉角色约束、去掉版本约束、去掉 Unknown 处理、只做来源限额等消融。
主比较 P−S 估计联合方案效果，组件归因来自对应消融；不能用一次全开/全关比较证明
每个模块分别有效。R4 的自动修订不得混入该主实验，主结果评分对象始终为原始生成答案。

若 P 未优于 S，保留较简单方案，把贡献定位为可审计的领域系统或负结果分析；
不通过追加通道或切换题集掩盖该结果。

## 7. R4：可核验输出、版本与安全后检

1. 所有比较臂使用同一“陈述—引用锚点”输出契约与提示要求，持久化实际生成的完整证据包。
   格式校验记录缺编号、越界编号、无法回指和缺支持，不将补造引用当成格式修复。
2. 版本核验分别记录 `stale_only`、`current_unavailable`、`no_citations`；新版不可得属于
   检索/语料限制，无引用属于无法核验。检测到的问题与答案是否真实错误分别计数。
3. 安全规则仅作为筛查信号，与 Judge 独立记录。规则需测试否定、转述、引用和建议语境；
   出现风险短语不能直接判违规。规则/Judge 阳性、分歧及预先抽取的双阴性样本进入专家复核，
   以便估计误报与漏报，而非只审核被标记答案。
   记录各层抽样概率，估计总体检测性能时加权；不能直接用富集阳性样本的比例代表整体。
4. 审核队列输出原文 span、触发规则、Judge 理由及候选依据。误报不自动进入评分，
   基础设施失败、待复核与明确通过分开表示；人工审核未完成不记作安全通过。
5. 若引入补检索或重新生成，另做“原始答案 / 后检后修订”配对实验，计入新增调用、延迟和
   人工负担。保存全部版本，不挑选一次通过的结果覆盖原始失败。

开发阶段的输出契约目标为有效编号可解析率 ≥99%、必需陈述有效引用覆盖率 ≥95%；
这是工程验收目标，不是临床安全阈值。不能用只输出空答或拒答来满足引用目标。
单题重复探针用于了解生成变异；既有四次观测不足以确定违规率，也不足以定位因果根因。

## 8. R5：冻结协议、指标与统计

### 8.1 冻结条件与运行记录

在打开隐藏集结果前冻结：代码提交、语料/索引快照、数据与分组指纹、模型标识、prompt、
评分配置、角色规则、候选深度、M/k/B、来源映射、重试策略和全部臂配置。
默认沿用 `gpt-5-mini` 生成、`gpt-5` Judge、`text-embedding-3-large` 向量；模型或服务版本
变化作为新实验批次记录。复用索引须通过语料和索引元数据核对，不默认复用陈旧 namespace。

每条记录至少保存：`question_id / scenario_family_id / arm / repeat_id / run_id`、原始排名、
过滤和选择理由、实际上下文与 token、原始答案、引用映射、Judge/规则/专家各自结果、
usage、错误、重试和缓存命中。required Judge 或应调用的 safety Judge 失败均记单元失败，
不以 lexical 回退掩盖。评分所用上下文必须等于实际生成证据包，不静默截取前段。

### 8.2 指标与初始判定目标

| 层级 | 指标与分母 | 用途 |
| --- | --- | --- |
| 主终点 | **不适用证据使用错误率**：每份有效答案是否存在至少一项由不适用证据、未满足条件或不当版本支持的临床断言，由专家判定；按家族等权汇总 | P 相对 S 的主要研究效果 |
| 质量护栏 | final、faithfulness、completeness、必需陈述覆盖率、恰当回答/无依据拒答率 | 防止删证据或拒答换取较低错误率 |
| 可核验性 | 有效引用覆盖的必需陈述数 / 全部必需陈述数；正确支持的引用数 / 全部引用数；缺引用与错误引用分别计数 | 不以“已引用的少数陈述”替代完整覆盖分母 |
| 条件敏感性 | 应改变的内容正确改变率，以及不应改变内容的保持率；均按情境家族统计 | 检查条件化行为，避免一律改变或一律保持 |
| 版本/冲突 | 错用旧版率、适用范围混合率、真实分歧披露率；使用预先标注的适格题作分母 | 定位联合机制的收益 |
| 系统代价 | 每题 tokens、模型调用、端到端延迟、人工复核率、失败率；建库与推理分列 | 判断实际代价，报告中位数与尾部延迟 |

缺引用不能自动记为主终点零错误：专家仍按断言内容与已知条件判断；确实无法判定时标为
不可判定并进入缺失分析，同时计入引用覆盖缺口。恰当的条件解释、版本比较和分歧呈现
不因包含旧版或未知条件而自动判错。指标无适格分母时报告 N/A，不记作满分。

建议的初始研究目标：主终点相对 S 的错误率**绝对下降至少 5 个百分点**，且配对差
95% CI 上界 <0；final 的 P−S 差值 CI 下界 >−0.01，faithfulness/completeness
及必需陈述覆盖率各自下界 >−0.02，无依据拒答率差值上界 <+0.02。
前者要求点估计达到实际效应目标并有方向性证据，不等同于已证明
真实下降至少 5 个百分点；后者为预先定义的非劣目标，不能用“不显著”替代。

上述数值是规划起点，不是医学可接受风险标准。R2 开发试标后，由研究与临床评审依据
基线错误率、可接受损失和标注可靠性确定，写入冻结协议；若错误率低到不支持该目标，
在看隐藏集前调整研究范围或设计。运行后不得移动阈值，也不凭总分抵消严重错误。
质量护栏与回答覆盖不满足时，不声称获得总体有效改进。

### 8.3 重复、区组与分析

- 默认每题每臂 3 次独立生成；每份答案一次 Judge，预先固定的 10% 家族增加重复 Judge
  以估计评分波动。生成重复与 Judge 重复分别记录，不挑最高分。
  生成缓存键必须区分臂、重复、模型和 prompt/证据指纹；跨重复复用答案不算独立生成。
- 单条测量为“题目×臂×重复”，推断的聚类单位为情境家族；同题变体及重复生成不能增加
  独立样本数。先在题内、家族内汇总，再计算家族等权的配对差与区间。
- 按“同题×重复”交错运行各臂，区组内随机臂顺序，平衡日期/批次；种子固定为
  `20261010` 并保存调度表。该种子只控制调度，不能宣称锁定不支持 seed 的模型采样。
- R1 对三个预定因子对比报告效应量、按题/已知家族聚类的 bootstrap CI；若作检验，
  对三个对比实施 Holm 校正。开发结果不能替代 R5。
- R5 的唯一主比较为 P−S 的主终点，采用家族级配对置换检验和按家族 bootstrap 95% CI
  （10,000 次，随机种子固定），双侧 α=0.05。预定比较直接执行，不事后依据 Friedman
  结果改变检验路径。P−L 及其他次要比较单列比较族并 Holm 校正，报告 `p_raw` 与 `p_holm`。
- 功效/精度模拟以主终点和质量护栏共同通过为目标，考虑配对、家族相关及预期缺失；
  在冻结协议中写明家族数、假设、目标功效和资源上限。测试期间不因接近显著而追加样本；
  后续增样必须作为新预注册实验。
- API/解析等技术错误最多 2 次重试，不因答案质量差、风险标记或低分而重生成；全部尝试
  留存。失败不插补为正常分，报告各臂 `n_failed` 和完整配对的有效分母。
  主分析保留完整家族；同时报告丢失家族及按可用题配对的敏感性分析。
  对二元主终点给出缺失在两臂取相反最坏取值的界限，避免选择性失败制造优势。
- 隐藏挑战集与旧 50 题分别报告；挑战集的错误率描述该任务分布，不能外推真实临床发生率。

## 9. 资源预算与停止条件

### 9.1 调用量估算

设题数 Q、实验臂数 A、生成重复 R，则生成调用基数为 `Q×A×R`，生成 Judge 同量。
安全 Judge、重复 Judge、嵌入、重试与修订调用另计。美元成本按 R0 实测 token 分布和
实际费率估计，不沿用历史混合链路的费用表。

| 阶段 | 规划规模 | 生成 + 基础 Judge 调用 |
| --- | --- | ---: |
| R1 旧集因子实验 | 50 题 × 4 臂 × 3 重复 | 600 + 600 = 1,200 |
| R3 开发机制实验 | 约 10 家族 × 3 变体 × 3 主臂 × 3 重复 | 270 + 270 = 540；组件消融另计 |
| R5 隐藏集初始预算 | 约 60 家族 × 3 变体 × 3 臂 × 3 重复 | 1,620 + 1,620 = 3,240；最终随样本量冻结 |

按上述 R5 规模，主比较 S/P 共 1,080 份答案需双人审核，即至少 2,160 次独立答案审核，
另加题目 gold 审核、分歧仲裁和安全后检复核。专家工时用试标耗时估计；资源不足时缩减
研究范围或调整设计并重新计算精度，不能用自动 Judge 悄然替代已登记的主终点。

同一网关初始并发 1–2，建库串行。连续 3 次基础设施失败或最近 20 单元失败率 >10%
时停下该运行排查，恢复后按调度续跑；这类技术中断不构成科学结论。每阶段事前记录 token、
调用和人工工时上限，超额时保留中断状态，不只报告成功子集。

### 9.2 研究决策

| 观察 | 决策 |
| --- | --- |
| 前置/去冗余只有检索改善，答案质量无可检测收益 | 保留回归与负结果，不继续增加召回通道；检查条件触发面和信息缺口 |
| 未证实完整 PACE 优于强简单对照 | 优先简单实现，降低联合算法创新主张；区间宽时明确结论不确定 |
| 错误率下降但 completeness、回答覆盖或失败率恶化 | 视为质量取舍，不能宣称总体优越 |
| 引用或后检覆盖不足 | 优先修复可观测性；不以“未发现问题”推断通过 |
| 专家不足或真实冲突原文不全 | 继续工程与开发探针，确认性研究保持待完成 |
| 独立验证通过且成本可接受 | 整理论文方法、消融与复现产物；另规划临床流程验证 |

本期不默认启动 embedding/reranker 微调、多模态、更多召回通道或跨框架合并。
只有误差分析显示“相关且适用证据持续被排低”，且困难负例与独立数据充足时，才为领域训练
另开协议。GPU 可用性不作为训练理由。

PathRAG 仍按网关基础设施依赖单列。网关恢复后可补齐历史协议并重新汇总对应框架比较；
若加入本轮实验，必须满足本轮数据、prompt、预算与评分条件，不能直接追加旧产物。
它不阻塞 PACE 主研究。L4 专家审核则阻塞相应确认性安全结论。

## 11. 方法来源

本计划采用 `experimental-design` 技能的因子设计、区组随机化与避免伪重复原则，并结合
仓库现有研究设计和专家审核方案。方法参考：Fisher, *The Design of Experiments* (1935)；
Hurlbert, “Pseudoreplication and the Design of Ecological Field Experiments” (1984)。

技能方法来源：Kassis, T., Agarwal, V., He, Y., Patel, D., & Brueckner, A. M. (2026).
*Scientific Agent Skills: A Library of Procedural Knowledge for Research Agents*.
[arXiv:2609.00065](https://arxiv.org/abs/2609.00065)，
[DOI](https://doi.org/10.48550/arXiv.2609.00065)。作者与题名已于 2026-10-10 对照 arXiv 元数据核验；
该来源用于说明实验设计工作流，不作为 PACE 新颖性或有效性的证据。
