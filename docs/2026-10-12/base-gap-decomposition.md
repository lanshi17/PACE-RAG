# R3 前置：base 差距分解（2026-10-12，零 token 分析）

> 问题：R1 四臂 final ≤0.9123 vs LightRAG 原生 0.9193（62 题，跨管线路径）。
> 本文保留探针前的分析思路。后续 C1/C2 已执行，但未隔离上下文、prompt 与评分
> 口径，**归因尚未完成**；当前结论以 [C1/C2 核验记录](c1-c2-results.md)为准。

## 1. 初始线索：检索汇总分接近，证据选择与 prompt 均待排查

| 证据 | 数值 | 解读 |
|---|---|---|
| LR 原生检索质量 | recall 0.9677 / precision 0.7339 / mean 0.8969 | 与 R1 各臂检索面相当 |
| R1 A00 生成 weighted_mean | 0.8989 | 低于 LR 原生 0.9122 |
| 源集合 Jaccard（LR 原生 vs A00 kept） | **均值 0.503**（分布 0.1–1.0 全谱） | 来源集合重叠有限；不能直接换算为证据文本的重叠比例 |
| R1 生成 prompt | PACE `[E1..En]`（`build_generation_messages`） | LR 原生用 LightRAG 自带 prompt |

关键事实：R1 的 A00（无前置过滤、无去冗余、纯 RRF 融合）与 LR 原生**不是同一
检索路径**。快照管线是 BM25(语料库) + LightRAG 图 + 向量（vdb）三路 RRF；LR 原生
是 LightRAG adaptive 路由（basic/local/drift；`hybrid` 是来源匹配口径）。
source-set Jaccard 0.503 提示证据组成值得排查；A00 与 LR native 的 final
差距为 −0.0129，点估计最高的 A10 与 LR native 差距为 −0.0070。检索汇总分
接近不保证具体证据相同，也不能排除检索差异对生成的影响。

## 2. 差距归因的两个候选（需一个对照实验区分）

| 候选 | 预测 | 检验 |
|---|---|---|
| ① 上下文组成差异（RRF 融合 vs LR 原生路由） | 固定 prompt、预算及评分，仅替换证据选择时 final 改变 | 需同条件检索/证据对照 |
| ② 生成 prompt 包差异（不止编号格式） | 同一冻结证据包，分别用 PACE 与 LR prompt 重新生成时 final 改变 | 需同证据 prompt 对照 |

两类因素可能交互，单次跨路径分数变化不能排定主次。已执行的 C1/C2 在上下文、
检索模式与评分上未保持同条件，不能承担上述隔离检验；后续设计见核验记录 §4。

## 3. 对 R3 的操作结论

1. **P vs S 可作限定条件的内部比较**：按计划 §6.2 共用宽候选、可用信息、
   prompt、模型、预算与评分条件，仅改变预定选择机制。固定 prompt 不证明它
   对 P/S 的影响相同，不能将跨路径差值当作常量偏移。
2. **H2 的外部效度仍待验证**：内部收益不能直接视为超过 LR 原生系统；应报告
   同生成条件的 L 对照，并另列原生端到端验证，不拼接历史分数作因果归因。
3. C1/C2 属于 R3 的探索性前置探针；完成运行不等于完成归因。后续 S 开发比较
   待配额，不因当前结果更换 prompt 重跑 R1。
