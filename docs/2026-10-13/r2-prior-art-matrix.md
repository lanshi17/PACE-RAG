[研究主文档](../2026-09-12/prenatal-ace-framework.md) §4–5 和

## 1. 方法—相似点—差异—需验证主张

“差异”列是 PACE 拟实现和验证的范围，不是仅凭摘要认定先例没有某项能力。
日期与核验深度见 §3；没有公开全文支持的排他性断言不进入贡献声明。

| 方法 / 先例 | 与 PACE 相似点 | PACE 拟检验的差异 | 需验证主张与对照 |
| --- | --- | --- | --- |
| [LightRAG](https://arxiv.org/abs/2410.05779) | 图与向量结合、双层检索、增量知识更新 | 在统一候选与预算内，对证据的使用角色、适用条件和版本作集合决策 | 与同 prompt、同预算的 L 对照比较；原生端到端另测。不能把 LightRAG 的历史成绩算作 PACE 收益 |
| metadata / 区间过滤；[范围类型语义](https://www.postgresql.org/docs/18/rangetypes.html) | 字段筛选、区间包含/重叠、开闭端点 | 临床条款条件不总是文档级元数据；Unknown 的使用角色与部分适用需要保留 | 与同信息的过滤方案比较不适用证据使用错误、有效回答与角色覆盖。旧集 gold-source recall 持平不证明过滤一般无用 |
| [MMR](https://doi.org/10.1145/290941.291025) | 兼顾相关性和已有选中内容的冗余 | 除多样性之外，需要保留同源互补条款、临床条件与真实分歧 | 在相同候选、信息、k/B 下选定强简单 S，比较 P−S；权重只在开发家族调节，不能为 P 设置较弱 MMR |
| [AdaGReS](https://arxiv.org/abs/2512.25052) | token 预算、集合相关性与冗余惩罚、贪心边际收益、自适应权衡 | 临床角色覆盖、条件相容和冲突保留的增量是否有价值 | 不能将贪心集合选择或预算约束单列为创新；至少做角色/版本/Unknown 消融。若声称优于先进集合方法，需增加该方法的可比复现或明确未比较 |
| [ScalDPP](https://arxiv.org/abs/2604.03240) | DPP 建模片段依赖、互补证据链、集合级训练目标 | 先研究无需训练的条件与角色约束；不是以“互补”一词建立原创性 | 集合互补、密度/多样性及训练目标已有直接先例；不将未实施的训练列为当前贡献 |
| [TrialGPT](https://www.nature.com/articles/s41467-024-53081-z) | 逐条临床资格判断、支持句定位、信息不足与不适用的区分 | 从患者—试验资格匹配转向回答所需的多条证据共同选取和断言约束 | 将条件匹配与联合选择分开消融；Unknown 或三值化本身不构成新颖性。两任务标签不能未经映射直接等同 |
| [TREC Clinical Trials 2023](https://www.trec-cds.org/2023.html) | 资格相关的临床检索与评测，是续记中的近邻 | 检索资格等级与证据对某一断言的适用性不是同一评测对象 | 本轮原始站点 406，标签定义和日期待重核；不得拿 eligible/excluded/not relevant 直接证明 PACE 三值分类是新机制 |
| [PICOs-RAG](https://arxiv.org/abs/2510.23998) | 将临床问题结构化为 PICO，用于检索 | 明确输入事实与未知条件，避免查询扩展补造患者条件 | 对缺失条件的合理分支解释、必要澄清和无依据拒答分别计数；结构化临床查询已有先例 |
| [Sufficient Context](https://arxiv.org/abs/2411.06037) | 区分上下文不足与模型未利用证据，研究选择性回答 | “有相关材料但条件不适用”与“可作一般解释但不能给个体结论” | 主终点下降须同时通过完整性与回答覆盖护栏，避免通过一律拒答获益；不能把弃答机制作为首创 |
| [TimelyRAG](https://arxiv.org/abs/2609.11572) | 修订文档重叠、部分条款更新、语义与时间检索 | 孕周、生效/替代范围与公开截止时间分别处理；新版不自动取代所有旧条款 | 版本链、部分替代、未核实替代、历史查询分别分层；与简单时间过滤/版本重排区分，禁止“年份新即适用” |
| [EvoTrustRAG](https://arxiv.org/abs/2608.07933) | span 支持的冲突图、知识演化与未决冲突、生成前保留或分离材料 | 判断差异是否来自孕周/人群/检查范围，并限制不相容材料的共同直接支持 | 在双侧原文齐全且专家确认同适用范围的题上评估真实分歧披露；不能声称冲突图或保留分歧本身创新 |
| [知识冲突综述](https://arxiv.org/abs/2403.08319) | context–memory、inter-context、intra-memory 的区分 | 本轮主要检验检索上下文间的临床适用与版本冲突 | 报告冲突来源，区分表面范围差异和真实矛盾；单个探针不足以定位全部错误机制 |
| [ALCE](https://arxiv.org/abs/2305.14627)、[ReClaim](https://aclanthology.org/2025.findings-naacl.55/) | 引用质量、回答正确性、句级引用及交替生成引用/陈述 | 加入条件/版本对临床断言的支持核验 | 编号可解析、引用可回指、内容支持和临床适用四者分别评估；引用格式不是临床正确的替代指标 |
| [SourceCheckup](https://www.nature.com/articles/s41467-025-58551-6) | 医学陈述—来源支持评估、医生核验 | 进一步检查该出处是否能在当前条件下支持该断言 | 误报、漏报、不可判定、缺引用分别记录，自动后检不替代专家主终点；无需引用的拒答也不能自动记为安全改进 |

## 2. 主张与 R2 任务的连接

| 主张 ID | 可检验问题 | 主要任务类别 | 最低证据 / 降低主张条件 |
| --- | --- | --- | --- |
| C1 | 条件与角色联合选取是否减少不适用证据使用？ | GA / PM / UN | 同候选、预算、prompt 和评分的 P−S；家族级专家标签。单项 recall 提升不够 |
| C2 | 是否保留有效互补内容，而非仅增加来源数？ | CE | 必需角色覆盖、同源互补条款支持、答案完整性；与 MMR/来源限额比较。若简单方案相当则保留简单方案 |
| C3 | 是否正确区分真实冲突、范围差异和版本演化？ | VC | 双侧原文、明确适用范围与专家裁决；缺源题只能支持“证据不足时行为”结论 |
| C4 | 是否正确使用 Unknown，同时保持可回答内容？ | UN，兼顾 GA / PM | 条件补充后的变化与同义对照的稳定性；不得把缺失信息默认为满足，也不得全面拒答 |
| C5 | 引用/后检是否提供额外可观测性？ | 全部；VC 为重点 | 引用覆盖、条件/版本支持、专家误报/漏报；R4 修订答案另作实验，不混入 P−S 原始答案主比较 |

R1 未获支持和已有 S 离线结果是开发证据，不证明 H2 成立。当前 MMR 尚待比较，
最终 S 尚未冻结；本矩阵不改变该执行状态。C1/C2 prompt 探针的跨路径差值不作为
常量校正项，见 [归因核验](../2026-10-12/c1-c2-results.md)。
